# Nur Quran – Offline Quran App

**Nur Quran** is a simple, privacy-focused, completely offline Quran reading app. It requires no permissions, no internet connection, and contains no ads or tracking.

## Features

- Read the complete Quran offline (Hafs & Warsh narrations)
- English translation included
- Tafsir (exegesis) included
- Clean, distraction-free interface
- No permissions required
- Lightweight and fast
